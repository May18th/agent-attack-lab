智弈破局 · 项目简介

问题与背景：针对智能体面临的提示词注入、越权调用和信息泄露风险，以及传统测试过程不直观、结果难复核等问题。

方案与机制："智弈破局"以 ACPs SDK 与梧桐互联平台为技术底座，设计了 Attacker、Defender、Arbiter 三体协同架构。平台结合生活场景、攻击意图与难度分级，在授权模拟靶场内生成对抗样本。依托智能体互联调用与留痕，构建了"攻击提交—分层防御—裁决评分—复盘迭代"的对抗闭环。

效果与创新：结合3D动态可视化与流式战报，直观呈现攻击路径、拦截结果与裁决依据，支持过程追溯与战局复盘。

应用与价值：作品可有效用于智能体安全测评、攻防教学及安全策略验证。

智能体攻防实验室 · 动画详解 角色与待机：待机状态显示红色 Attacker、蓝色 Defender 和中央蓝色 Core，三者持续自转。点击“开始攻防”后，Defender 释放蓝色粒子，从 Core 外侧建立四层球面防御壳；节点和连线沿球面分布，层标签为 L0、L1、L2、L3。
四层顺序：L0 输入清洗与边界校验；L1 意图识别、推理约束和越狱语义识别；L2 工具白名单、参数风险、权限鉴权、调用时序和模拟执行核验；L3 全链路审计、异常监测、应急控制与恢复、最终分类。攻击严格按 L0 → L1 → L2 → L3 推进，当前层没有完成或被 Arbiter 确认前，不会跳层。
Attacker 阶段：A1 读取战局并吸收环境粒子；A2 由绿色“样本库”球选择样本；A3 由紫色“意图和策略”球提供策略粒子；A4 构建 Payload；A5 授权与格式自检；A6 由 Arbiter 判断同源或新源；A7 发射；A8 接收公开裁决并复盘。绿色球第一回合出现，紫色球在开启跨局记忆时第一回合出现，否则从第二回合出现。
Payload 颜色：浅蓝 / 灰白色表示 Payload 刚在 A4 创建、尚未完成 A6 来源判定；红色表示同源 Payload，即相似度达到或超过 0.85；黄色表示新源 Payload，即相似度低于 0.85。新源黄色 Payload 无论被拦截与否，都在本回合结算后粒子化飞向 Defender，被吸收后显示“更新特征库”；红色同源 Payload 不触发这条更新动画。
Defender 检查粒子：当前层会生成带编号的蓝色粒子，例如 L0-1、L0-2、L0-3，或 L2-1 至 L2-5。每个编号对应一个真实检查点；攻击开始时按编号顺序高亮对应蓝色粒子，该粒子飞向 Payload 进行拦截或与攻击粒子融合。
拦截与穿透：蓝色粒子与 Payload 相撞并消散，表示该检查点成功拦截，防御层向外扩散绿色光波；检查通过但未拦截时，攻击点扩散一次水晶屏障。某层最后一个检查点仍未拦截时，Arbiter 确认整层穿透，才播放玻璃裂解并进入下一层。
L3 与裁决：L3-1、L3-2、L3-3 会向 Core 发出内收光波，Core 随风险闪烁；只有后端事件明确给出控制成功或失败证据时，才提前表现恢复或失控，否则保持风险态等待 Arbiter。L3-4 不抢先生成结论，Arbiter 输出唯一最终分类后才锁定攻击结果。安全对照使用独立外环展示，不覆盖攻击样本的 Core 裁决颜色。HUD、时间线和评分只显示已收到的 Agent / Arbiter 事件。
