# 管理后台入口设计

## 目标

在现有 FastAPI + React 公开体验之上，增加一个仅面向管理员的 `/admin` 入口，集中查看和操作已经存在的后端能力。后台用于运维和审计，不改变公开首页的体验，也不假设不存在的用户、团队、容器、CTF 或课程数据模型。

## 范围

- 战局列表、状态筛选、详情、评分、事件和审计记录。
- 对已结束战局执行删除；对失败战局执行重试；对运行中战局执行取消。
- dashboard summary、运行 metrics 的只读展示。
- 外部案例按关键词只读查询，并显示来源和溯源状态。
- 使用现有浏览器会话鉴权；后台在未登录时显示明确的登录/权限提示。

## 非目标

- 不迁移到 Django、Vue 或 Element Plus。
- 不新增用户、团队、Docker 容器、CTF 题库、Flag、文件资源或课程系统页面，除非后端先提供对应真实接口和持久模型。
- 不在前端保存或展示 API Key、私钥或其他敏感配置。

## 交互约束

- `/` 保持现有公开攻防体验；仅 `/admin` 加载后台应用。
- 操作按钮必须根据战局状态启用或禁用，并对删除、取消等高风险操作二次确认。
- 失败请求显示后端返回的状态和请求标识（如有），不把鉴权失败伪装成空数据。
- 后台只展示后端返回的真实字段，缺失数据使用“暂无”并明确来源。

## 验收

- TypeScript 类型检查和 Vitest 通过。
- Vite production build 通过。
- 公开前端原有测试仍通过。
- `/admin` 路径不影响 `/`、`/replay/...` 和现有登录流程。
