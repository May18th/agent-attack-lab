# 管理后台 3D 工作台设计

## 意图

将现有管理员后台升级为可操作的 3D 攻防实验室工作台，让管理员能在同一空间里观察运行态势、定位战局、查看审计链路和浏览外部案例，同时保留高密度、可键盘操作的 2D 管理界面。

## 目标

- 使用 Three.js 运行时在 React 管理后台内渲染稳定的 3D 场景。
- 将运行指标、战局、事件、审计和外部案例映射到统一的空间模型。
- 3D 视图支持旋转、缩放、节点选择、状态图例、减少动效和重置视角。
- 现有重试、取消、删除、分页、筛选、报告和鉴权行为保持不变。
- 桌面端优先，并在移动/低性能设备上自动降级为轻量场景或纯 2D 视图。
- 不引入 Blender 或 Unreal Engine 运行时；如后续需要专用资产，使用 glTF/GLB 作为静态资源。

## 非目标

- 不重写公开前端业务页面。
- 不新增不存在的用户、团队、Docker、CTF、课程或文件资源后端模型。
- 不把 3D 场景作为唯一操作入口，也不使用 3D 替代表格、筛选和确认弹窗。
- 不在本阶段接入 LLM 或新的实时数据协议。

## 设计

### 统一空间布局

- 中央场景：两个固定的角色节点（攻击、 防守）和一个调度中心节点，按当前战局/事件生成边和轨迹。
- 左侧导航：态势总览、战局、审计、案例；切换页面时保留相机与筛选状态。
- 右侧详情：选中节点或战局后显示现有 2D 详情、评分、事件和可用操作。
- 顶部状态条：服务健康、活动战局数、事件速率、最近错误和鉴权状态。
- 底部时间线：选中战局后按事件序列显示可回放节点，不自动执行破坏性操作。

### 页面映射

- **态势总览**：指标卡 + 3D 拓扑。节点颜色表示运行状态，边的脉冲表示事件流；无数据时显示可解释的空状态。
- **战局**：战局列表保持 2D，选中后在场景中突出对应节点，并在右侧展示现有详情和操作按钮。
- **审计**：3D 时间线按请求/战局/ACP 调用分层，敏感字段继续由后端脱敏；完整日志仍以可复制文本呈现。
- **外部案例**：案例作为只读信息节点，显示来源、哈希前缀和关联战局；不把外部案例误标为真实项目事件。

### 交互与可用性

- 鼠标拖拽旋转、滚轮缩放、双击节点聚焦；键盘可用 Tab 进入筛选和操作控件。
- 提供“重置视角”“暂停动效”“降低粒子”“切换 2D”四个明确控制。
- 高危操作仍通过现有二次确认按钮执行；3D 点击只选择对象，不直接删除/取消/重试。
- `prefers-reduced-motion`、WebGL 不可用或设备性能不足时自动进入 2D 降级。
- 场景图例、选中状态和关键数值同时以文本呈现，满足可读性和无障碍需求。

### 数据与性能

- 初版复用现有 `adminApi.ts` 的 dashboard、metrics、battle detail、events、audit、report、external cases 接口。
- 仅在页面可见且数据变化时更新场景；不在渲染循环内发请求。
- 使用实例化网格、对象池和固定上限，默认最多渲染 64 个活动节点、128 条关系边。
- Three.js 包按管理后台路由懒加载，公开前端不增加 3D 依赖。
- 场景刷新和详情请求继续使用现有竞态保护；卸载页面时清理渲染器、事件监听和定时器。

## 验收标准

- 管理员可打开 `/admin`，在认证通过后看到 3D 态势场景和完整 2D 管理面板。
- 选择战局、筛选状态、重试、取消、删除、查看审计/报告的现有测试继续通过。
- 无 WebGL、移动端窄屏和减少动效模式下页面仍可完成全部管理操作。
- `npm test`、TypeScript 检查、lint、生产构建通过；浏览器截图确认场景非空、无重叠、可交互。
- 不上传 `.env.local`、证书、数据库、`node_modules` 或任何长期记忆内容。

## 构建者决定

- 运行时采用 Three.js 原生 API，避免为单一管理页增加 React Three Fiber 的额外抽象层；若现有代码量证明声明式组件更易维护，再在实现阶段评估引入。
- 视觉采用深色、低饱和背景与青色/橙色状态色，服务于扫描和告警，不使用大面积渐变或装饰性 3D 物件。
- 先实现可验证的静态/轮询态势场景，再接入 WebSocket；本阶段不改后端协议。

## 已确认口径

- 审计 3D 时间线围绕当前选中的战局展示，使用现有战局审计/事件接口，不新增全局审计接口。
- 外部案例先作为独立只读节点展示；当前接口没有关联战局字段，因此不创建虚构的案例-战局连线。
- 导航在 `/admin` 内采用标签/视图切换，不新增独立后端路由；相机和筛选状态保留在当前 React 会话内。
