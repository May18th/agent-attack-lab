## 发布流程

1. 用回放库对候选记录执行固定测试，并提交安全对照样本。
2. 检查每个回合只有一个 Payload，确认事件、证据和样本谱系完整。
3. 由人工审核者填写 `reviewedBy` 和审核结果；只有通过的记录才能改为 `approved`。
4. 发布前重新运行后端测试和回合时间线回归测试，再部署生产环境。

Arbiter 的 `LIB-08`、`LIB-14`、`LIB-15`、`LIB-16`、`LIB-17` 仍为空，后续需要根据评分细则
补充余弦相似度、安全对照、隐藏真值、事件裁决和学习审核记录。
