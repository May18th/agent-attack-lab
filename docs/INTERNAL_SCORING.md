# 攻防实验室内部评分规则

更新时间：2026-10-13

## 适用范围

本规则分别评价单场中攻击 Agent 和防守 Agent 的输出完整度、执行完成度与可审计性，二者各自满分 100 分、独立出分。它不是比赛作品评分细则，不评价 UI 美观度、创新性、平台访问量或应用成效；也不代表攻击成功率、漏洞检出率、检测准确率、真实模型调用、目标系统已修复或真实目标安全性。

参考的《修改建议.doc》提出首页叙事、攻防对峙呈现和互联证明中心三个产品改进方向，但没有给出计分公式。本规则仅将可从现有战局与调用事件中复核的输出结构和运行证据计分；不对主观视觉效果计分，也不推断当前战局事件未记录的 Registry 注册、Discovery 命中或访问量事实。

## 攻击 Agent（100 分）

| 维度 | 分值 | 计算规则 |
|---|---:|---|
| 样本结构完整度 | 35 | 按样本中的 `type`、`topic`、`severity`、`scenario`、`objective`、`content` 六字段完整比例计分。 |
| 测试设计可复现性 | 20 | 按 `testCaseId`、`attackDepth`、`difficulty`、`testVariation` 四字段完整比例计分。 |
| 调用执行完成度 | 20 | 成功完成且关联到样本结果的攻击调用数 / 样本数 × 20。 |
| 样本调用可追溯性 | 15 | 样本事件经同一 `correlationId` 关联到已开始并已结束的攻击调用比例 × 15。 |
| 调用来源留痕 | 10 | 按成功调用中同时包含非空 `dispatchMode` 与 `resultSource` 的比例计分。 |

## 防守 Agent（100 分）

| 维度 | 分值 | 计算规则 |
|---|---:|---|
| 逐轮响应完整度 | 25 | 每个样本都有防守响应，且 `caught`、`risks`、`fixed` 均为对象数组时，按完整轮次比例计分。三数组为空也允许，避免把“未命中”误判为错误格式。 |
| 分析依据完整度 | 20 | 有发现时要求发现/风险有理由和证据/依据，并有 `verificationStatus` 或 `analysisMode`；无发现时要求明确记录分析状态，按轮次比例计分。 |
| 修复建议可验证性 | 20 | 有修复建议时要求每条包含 `action`、`verificationSteps`、`passCriteria`、`failCriteria`；无命中且无风险时不因无需建议而扣分，按轮次比例计分。 |
| 防守调用完成度 | 20 | 成功完成且关联到防守回合的调用数 / 样本轮数 × 20。 |
| 回合调用可追溯性 | 10 | 防守回合经同一 `correlationId` 关联到已开始并已结束的防守调用比例 × 10。 |
| 调用来源留痕 | 5 | 按成功调用中同时包含非空 `dispatchMode` 与 `resultSource` 的比例计分。 |

各维度按整数四舍五入。缺少某个角色的 Agent 调用事件时，该角色状态为 `insufficient_evidence`、分数为 `null`；不会把证据缺失当作零分。运行失败或不完整的角色可按已经留存的证据获得部分分。

## 解释边界

- 两套分数独立，不合并成单一胜负分；现有战报里的攻击/防守游戏积分和 `/leaderboard` 继续保留，不与本规则混用。
- `dispatchMode=acp` 表示走 ACP 远端调用；`resultSource=acp-rule-fallback` 表示远端 Agent 使用了规则兜底，不能称为真实模型调用。来源字段只是运行记录，不是模型提供方独立证明。
- `caught`、`risks`、`fixed` 的条目数量不直接加分，避免奖励未经验证的命中数和建议数。当前分数评价结果的结构与证据，不评价判定对错。
- 本系统当前没有对每个主题和样本建立独立、经人工验证的 ground truth，因此不计算精确率、召回率、误报率或漏洞修复率。
- Registry 注册、Discovery 状态、平台访问量、视觉叙事与真实目标修复须由各自可核验来源证明，不由 Agent 评分推定。

## 查询接口

- `GET /battles/{battle_id}/score`：查看单场攻击与防守的独立评分及分项。
- `GET /reports/{battle_id}`：战报 JSON 同时返回 `internalScore.attacker` 和 `internalScore.defender`；Markdown 战报列出两侧得分及分项。
- `GET /internal-scores?limit=50`：查看近期逐战评分、攻击/防守各自的均分和证据不足数量。

以上接口沿用后台读取鉴权。分数从留存战局和事件实时派生，不保存脱离原始证据的分数副本；删除战局后，该战局评分随之消失。规则版本为 `internal-agent-v2`；旧战局也按当前版本实时重算，不保留历史分数快照。

## 后续校验

如需评价攻击/防守实际效果，必须先为各类别建立独立、可复现并经人工确认的测试样本及期望结果，再以验证后的真值计算检测指标；不能直接把 Agent 自报结果当作真值。
